# `IConfigMigrationDefinition`

Interface describing a migration definition (`up` / `down`).

Transaction-enabled execution and rollback pass the exact `crud-config-migrations` owner manager to callbacks. Forward a defined manager as `eventManager` to each `CrudConfigService` operation. Execution with `useTransaction: false` passes `undefined`.
