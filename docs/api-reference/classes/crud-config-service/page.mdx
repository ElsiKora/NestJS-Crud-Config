# `CrudConfigService`

Main programmatic API to read/write configuration values.

_Defined in: `src/modules/config/config.service.ts`_

## API

```ts
export class CrudConfigService {
 delete(options: IConfigDeleteOptions): Promise<void>;
 get(options: IConfigGetOptions): Promise<IConfigData>;
 getList(options: IConfigGetListOptions): Promise<IConfigData[]>;
 set(options: IConfigSetOptions): Promise<IConfigData>;
}
```

## Transaction contract

`set()` without `eventManager` owns the named `crud-config-set` Automator transaction. A provided `eventManager` must be the exact manager already bound to an active Automator owner; it joins that owner and does not establish context for an arbitrary TypeORM manager.

Transaction-enabled migrations pass their `crud-config-migrations` owner manager to the callback. Forward it through `eventManager` on every config operation.
